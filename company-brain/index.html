This is not a chatbot over your documents. Tacit extracts procedures as structured objects with conditions and branches, keeps them current, and hands them to agents in a format they can run.

An executable format

Trust is the product

A confidently wrong procedure is worse than none. Every step shows the evidence it was derived from, how many tickets agree with it, and who owns it. When confidence is low, the agent hands off instead of guessing.

Open Procedure Schema · v0.3

The format agents run

Every procedure exports as a skills file for agents and as portable JSON. Whoever owns the format for "how this company runs" owns the category, so the schema is designed to be published as an open spec.


        

      

      

        
What's in a procedure

        

          
triggerIntents and phrases that route a ticket here, plus any customer-specific match.

          
inputsFacts the agent must fetch before acting, and which system holds each one.

          
stepsChecks, actions, escalations and replies. if nodes carry a machine-testable condition.

          
guardrailsThings the agent must never do, learned from incidents and policy.

          
provenanceTickets, threads and calls behind every step, with agreement and confidence.

          
driftVersion, the date the current behavior started, and open drift flags.

        

        
An agent should refuse to run a procedure below its confidence floor and hand the ticket to a person. In this workspace the floor is 60%.
